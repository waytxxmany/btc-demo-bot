# BTC Demo-Bot

Демо-бот для торговли Bitcoin: котировки, индикаторы RSI и MA, торговые сигналы и бэктестинг.

## Project Goal

Создать демо-бота для торговли Bitcoin (BTC), который получает рыночные котировки, рассчитывает индикаторы RSI и MA, формирует торговые сигналы и тестирует стратегии на исторических данных. В дальнейшем добавить торговлю на виртуальном балансе и уведомления.

## Инструкция по запуску

### Требования

- **Python 3.11 или новее**
- **Git**

### Клонирование

```bash
git clone https://github.com/<ваш-ник>/btc-demo-bot.git
cd btc-demo-bot
```

### Установка и запуск

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` в корне проекта и укажите настройки:
   ```
   UPDATE_INTERVAL_SECONDS=60
   ```
4. Запустите проект:
   ```bash
   python main.py
   ```

> Файл `.env` и база данных `*.db` не попадают в репозиторий (они указаны в `.gitignore`). База с котировками создаётся автоматически при первом запуске.
