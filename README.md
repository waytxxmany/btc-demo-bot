# УПП_24.25_3

Демо-бот для торговли Bitcoin: котировки, индикаторы RSI и MA, торговые сигналы и бэктестинг.

## Project Goal

Демо-бот для трейдеров, который анализирует котировки Bitcoin через индикаторы RSI и MA и позволяет тестировать торговые стратегии на исторических данных без финансовых рисков

## Инструкция по запуску

### Требования

- **Python 3.11 или новее**
- **Git**
- **Аккаунт Telegram** и токен бота от [@BotFather](https://t.me/BotFather) (команда `/newbot`)

### Клонирование

```bash
git clone https://github.com/<ваш-ник>/<имя-репозитория>.git
cd <имя-репозитория>
```

### Установка и запуск

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе примера и впишите токен бота:
   ```bash
   copy .env.example .env
   ```
   Затем откройте `.env` и укажите `BOT_TOKEN=ваш_токен`.
4. Запустите бота:
   ```bash
   python -m src.bot
   ```

### Команды бота

- `/price` — последняя цена BTC
- `/history` — последние 10 записей истории
- `/rsi` — значение индикатора RSI
- `/ma` — скользящая средняя MA
- `/signal` — сигнал на покупку или продажу

> Бот сам собирает котировки, пока запущен. Для расчёта RSI нужно минимум 15 записей, для MA 20, поэтому после первого запуска подождите несколько минут. Файл `.env` и папка `data/` с базой котировок не попадают в репозиторий (они указаны в `.gitignore`), база создаётся автоматически при первом запуске.
